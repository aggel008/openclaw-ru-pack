## 🚀 Установка

Каждый скилл устанавливается отдельно. Скопируй папку скилла в директорию `skills` своего OpenClaw workspace:

```bash
# Пример для macOS/Linux
cp -r dogovor-ru ~/.openclaw/workspace/skills/
cp -r zhkh-ru ~/.openclaw/workspace/skills/
cp -r analizy-ru ~/.openclaw/workspace/skills/
cp -r pretenziya-ru ~/.openclaw/workspace/skills/
cp -r chinovnik-ru ~/.openclaw/workspace/skills/
cp -r nalog-ru ~/.openclaw/workspace/skills/
```

Или установи весь пак сразу:

```bash
git clone https://github.com/aggel008/openclaw-ru-pack.git
cp -r openclaw-ru-pack/*/  ~/.openclaw/workspace/skills/
```

После этого OpenClaw подхватит скиллы автоматически — перезапуск не нужен.

## 💬 Примеры использования

**Договор:**
> "Объясни мне этот договор аренды: [вставь текст]"

→ Получишь разбор по пунктам, красные флаги и вывод — подписывать или нет.

**ЖКХ:**
> "Расшифруй мою квитанцию: холодная вода 450р, горячая 820р, отопление 2100р, капремонт 249р"

→ Получишь таблицу с объяснением каждой строки и итогом к оплате.

**Анализы:**
> "Объясни результаты: гемоглобин 110 г/л, лейкоциты 9.2, СОЭ 24"

→ Получишь расшифровку отклонений простыми словами и что сказать врачу.

**Претензия:**
> "Помоги написать претензию в магазин — купил телефон, он сломался через неделю, отказываются менять"

→ Получишь готовый шаблон со ссылками на закон и инструкцией как подать.

**Чиновничий:**
> "Что значит это письмо из налоговой: [вставь текст]"

→ Получишь перевод на человеческий + что конкретно нужно сделать и в какой срок.

**Налог:**
> "Я самозанятый, получил 120 000 рублей за месяц от юрлиц. Сколько плачу?"

→ Получишь точный расчёт с объяснением.
